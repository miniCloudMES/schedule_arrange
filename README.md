# Schedule Arrange

## 簡介
此專案是一個服務業預約排程系統，使用純前端技術（HTML、CSS、JavaScript）實作，提供使用者快速建立、管理與檢視預約。

## 目錄結構
```
Schedule_Arrange/
├─ index.html      # 主頁面
├─ style.css       # 版面樣式
└─ app.js          # 前端邏輯
```

## 本地執行
1. 確認已安裝 Node.js（建議 14+）
2. 在專案根目錄執行 `npm init -y && npm install`（目前無依賴）
3. 使用簡易 HTTP 伺服器啟動，例如：
   ```bash
   npx serve .
   ```
   然後在瀏覽器開啟 `http://localhost:3000`。

## 功能概述
- 新增、編輯、刪除預約
- 預約列表即時顯示
- 客製化樣式與主題切換
- 可擴充的模組化 JavaScript 結構

## 使用說明
- **新增預約**：在表單填寫客戶資訊與時間，點擊「新增」即可加入列表。
- **編輯預約**：點擊列表中的編輯按鈕，修改資訊後保存。
- **刪除預約**：點擊刪除按鈕即可移除該筆預約。
- **主題切換**：在設定中可切換深色/淺色主題，介面會即時更新。
